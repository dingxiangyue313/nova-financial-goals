# NOVA 自适应目标方案搜索

## 用户路径

用户明确目标金额、日期、已存金额、月存上限和保护资金后，Agent 先读取模拟财务概况和数据充分性，再调用 `search_goal_options`。服务端在当前任务与 Financial Twin 快照内寻找可直接执行的固定月存基线方案，最多返回三个预计完成日期不同的候选。Agent 只能推荐搜索工具返回的、当前任务中已保存的 `candidate_preview` 结果 ID。选择候选后仍须走原有冻结 Action 与单独确认链路。

## 搜索边界与算法

- 搜索只使用模拟数据；金额为整数分，日期为 ISO 格式。目标金额、原目标日期、月存上限与保护资金不由模型放宽。
- 月存上界为用户上限、月度可投入额和首月实际可投入额的最小值。首月缓冲为负的固定月存方案不作为可直接选择的候选。
- 对确定性 `assessCandidateScenario` 用二分搜索查找最低按时月存额，再查找预计完成日期发生变化的金额边界。相同日期的更高月存额不进入结果。
- 结果按 `lower_monthly`、`higher_buffer`、`earlier` 或 `balanced` 目标排序；偏好只影响排序，不改变可行性。结果可能只有零个、一个或两个，不为凑数量生成方案。
- “无方案”只指当前日期、固定月存方式、已设硬约束与模拟数据中的搜索范围；不代表其他条件或分段存款方式一定无解。

## 工具与状态

`search_goal_options` 是只读白名单工具，输入只有搜索目标和最多三项结果。工具自行读取当前任务和 Twin，保存每个入选候选为普通 `candidate_preview` 结果，再保存搜索摘要。摘要包含搜索金额范围、计算次数、候选结果 ID、排除原因、来源、假设和数据缺口。任务修订或 Twin Version 变化后，旧候选不能被推荐或确认。模型重复输出无效 JSON 时最多重试一次；模型不可用时确定性回退也使用同一搜索器。

候选卡片沿用 NOVA 原有视觉，按月存与日期差异显示“轻松存”“均衡存”“提前存”或“当前可行节奏”。模型生成的解释仍须通过金额、日期和候选 ID 来源校验。搜索和推荐均不修改正式目标、余额或保护资金。

## 验证与当前限制

- 离线测试覆盖结果去重、首月缓冲、数据不足、无解范围、工具结果归属、Agent 自主搜索与确认链路；完整回归结果以本分支测试输出为准。
- 真实 DeepSeek 隔离模拟评测中，可行目标已观察到“读取 → 搜索 → 引用已核验候选 → 推荐”的完整路径。模型偶发返回不符合 JSON 契约的决策，系统会有界重试或使用确定性回退；真实模型通过率需要更大样本才能判断。
- 当前预测仍沿用 `assessCandidateScenario` 的月度近似模型；搜索不支持首月少存、以后补足的分段计划，也不计算概率或真实银行资金。后续若要支持分段计划，须新增方案类型和相应的服务端计算器。
