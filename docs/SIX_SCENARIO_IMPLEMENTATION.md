## 合成数据

- 原有 186 行基准：10 月净支出 477,800 分，工资卡 724,000 分，旅行金 200,000 分，最低余额 317,200 分。
- 三套含 40+ 商户变体、合成收入/项目款、配对退款、重复与内部转账的可预览后合并历史：旅行 2,400 行、不规则消费 1,800 行、长期目标 1,800 行，共 6,000 行，覆盖上一完整年度及当年。
- 20 位合成联系人、同名消歧、6 个虚拟投资产品、3 张初始卡、机票及住宿两个签名模拟商户。
- CSV/XLSX/PDF/PNG 四种 18 行等价样例在 `public/samples/formats/`；OCR 使用本地英文字库。

导入丰富历史会改变账单统计，不应继续用原 186 行基准金额作为该会话的期望值。以上历史是消费证据，不等于新的账户资产或收入承诺。

日期现金流现在提供余额曲线、逐日表、工资延迟三天与额外支出的只读试算；不修改余额或扩大原授权。可用余额与执行使用同一低谷计算，切换主目标不会改变旅行钱包原归属。

## 治理与状态

所有新增金融写操作先经严格共享 Schema，再准备绑定准确参数、Twin 版本和到期时间的服务端审批；确认时重新核验权限、风险及当前条件，执行后返回状态并进入 Hash 审计。金额为整数分，投资份额采用整数微份额，费用使用整数运算。

同一确认 ID 可安全重复查询；跨会话 ID、过期/失效/取消确认不能执行。未知操作保留资金占用，查询原操作才可结算或释放；不因重试生成第二笔付款。

新增服务状态持久化在 SQLite 会话状态中，与审批、余额、审计原子写入。它是可恢复的本地模拟提供商，不宣称已实现外部金融机构的分布式事务或真实清算。

Registry 现在是 13 项。新增联系人与 AA、投资生命周期、卡片生命周期；授权与旅行请求提供有校验的只读调查。模型不能获得 execute/confirm 权限。新增适配器支持会话、引用、时间与调用预算校验，产品写入仍由独立确认完成。
