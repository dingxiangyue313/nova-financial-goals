# 合成账单样例

全部内容由确定性代码生成，不包含个人金融信息。金额字段为整数分，负数表示支出。

| 文件 | 来源 |
| --- | --- |
| nova-synthetic-statements.csv | 合并三来源，共186条 |
| nova-bank.csv | 模拟银行卡 |
| nova-wechat.csv | 模拟微信 |
| nova-alipay.csv | 模拟支付宝 |

覆盖2026年5至10月。包含工资、房租、水电、保险、交通、日常采购、餐饮、CloudBox Plus续费、内部转账双边记录与原路退款配对。

10月计入消费的合计为477800分；餐饮71000分，相比5–7月每月40000分增加31000分。退款订单的支出和退款均排除，内部转账不计消费。历史流水不能覆盖权威余额。

样例生成源为 `server/mission.ts` 中的 `sampleRows()`。应用当前的导入按钮使用服务端内置合成记录并去重；任意文件上传及XLSX/PDF解析尚未开放。
